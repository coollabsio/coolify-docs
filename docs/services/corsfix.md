# Corsfix

<ZoomableImage src="/docs/images/services/corsfix.webp" alt="Corsfix CORS proxy banner" />

## What is Corsfix?

Corsfix is the open source and secure CORS proxy platform that lets you fetch any API directly from client side JavaScript without getting CORS errors.

## Setup

For deployment via Coolify, you only need to provide two environment variables, which are `APP_DOMAIN` and `PROXY_DOMAIN`.

These are used for the "Playground" feature, which allows you to call your proxy right from the Corsfix dashboard (app).

For reference, in the hosted service, they are `app.corsfix.com` and `proxy.corsfix.com` respectively.

The rest of the variables are automatically generated by Coolify, unlike with the manual [self-hosting setup](https://corsfix.com/docs/open-source/self-hosting?utm_source=coolify.io).
