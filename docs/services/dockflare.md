## What is DockFlare?

DockFlare is a self-hosted ingress and access-control plane for Cloudflare Tunnel environments. It watches your Docker containers and automatically translates their labels into Cloudflare configuration — creating tunnel routes, DNS records, and Access policies without any manual dashboard work.

It includes a web UI for adding manual routes for non-Docker workloads, support for reusable Access Group policies, multi-zone DNS handling, and a master/agent architecture for managing multiple hosts from a single control plane.
