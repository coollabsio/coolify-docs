# PowerSync

<ZoomableImage src="/docs/images/services/powersync-logo.svg" alt="PowerSync logo" />

## What is PowerSync?

[PowerSync](https://www.powersync.com/?utm_source=coolify.io) is an open-source & source-available sync engine that replicates data from a backend database into a local SQLite database on each client, enabling instantly-responsive offline-first and local-first apps. Supported source databases: Postgres, MongoDB, MySQL, and SQL Server.

## Notes on deployment

Set the following environment variables before deploying:

- `PS_DATABASE_TYPE` — source database type (default: `postgresql`; set to `mongodb`, `mysql`, or `mssql` for other sources)
- `PS_DATABASE_URI` — connection string to your [source database](https://docs.powersync.com/configuration/source-db/setup?utm_source=coolify.io)
- `PS_SYNC_BUCKET_TYPE` — storage type for PowerSync's internal state (default: `postgresql`)
- `PS_SYNC_BUCKET_URI` — connection string for the storage database (can be the same as `PS_DATABASE_URI`)
- `PS_JWKS_URL` — JWKS endpoint from your [JWT auth provider](https://docs.powersync.com/configuration/auth/overview?utm_source=coolify.io)

`PS_API_TOKEN` is auto-generated by Coolify.

After deploying, edit **sync-config.yaml** under **Storages → Files** to define which tables sync to clients.

For a full walkthrough including a Supabase example (the fastest way to get started), see the [PowerSync Coolify guide](https://docs.powersync.com/maintenance-ops/self-hosting/coolify?utm_source=coolify.io).
