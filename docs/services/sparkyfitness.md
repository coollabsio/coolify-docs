# SparkyFitness

<ZoomableImage src="/docs/images/services/sparkyfitness.webp" alt="SparkyFitness Logo"/>

::: warning Upgrading from v0.15.x to v0.16.x
SparkyFitness v0.16 introduces breaking changes to its environment variables. If you deployed SparkyFitness before this update, refresh the service from the latest template so Coolify can add the new variables and secrets before redeploying:

- `JWT_SECRET` has been replaced by `BETTER_AUTH_SECRET` (auto-generated by Coolify).
- A new unprivileged application database user is now required — `SPARKY_FITNESS_APP_DB_USER` and `SPARKY_FITNESS_APP_DB_PASSWORD` (auto-generated). The original `SPARKY_FITNESS_DB_*` superuser is now only used for migrations.
- New optional variables: `SPARKY_FITNESS_FORCE_EMAIL_LOGIN`, `SPARKY_FITNESS_EXTRA_TRUSTED_ORIGINS`, and `ALLOW_PRIVATE_NETWORK_CORS`.

See the [upstream release notes](https://github.com/CodeWithCJ/SparkyFitness/releases?utm_source=coolify.io) for the full list of changes.
:::

## What is SparkyFitness

SparkyFitness is a comprehensive fitness tracking and management application designed to help users monitor their nutrition, exercise, and body measurements. It serves as a self-hosted alternative to MyFitnessPal with AI-powered nutrition assistance, giving you complete control over your fitness data.

The application provides tools for daily progress tracking, goal setting, and insightful reports to support a healthy lifestyle with privacy and data ownership at its core.
