## What is Cassandra

Cassandra is an open-source, distributed NoSQL database management system designed for handling large amounts of data across many commodity servers with high availability and no single point of failure.

It offers linear scalability, fault tolerance, and tunable consistency, making it suitable for applications that require high write and read throughput across geographically distributed data centers.
