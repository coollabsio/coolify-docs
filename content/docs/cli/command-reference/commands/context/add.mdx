# Add

Add a new context

## Usage

```sh
coolify context add <context_name> <url> <token>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--default (-d)` | `boolean` | No | `false` | Set as default context |
| `--force (-f)` | `boolean` | No | `false` | Force overwrite if context already exists |

## Get current help

```sh
coolify context add --help
```

The installed CLI help reflects the exact options available in your CLI version.
