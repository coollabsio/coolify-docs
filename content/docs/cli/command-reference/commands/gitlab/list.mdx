# List

List all GitLab App integrations configured in Coolify for the current team (includes system-wide sources).

## Usage

```sh
coolify gitlab list
```

## Get current help

```sh
coolify gitlab list --help
```

The installed CLI help reflects the exact options available in your CLI version.
