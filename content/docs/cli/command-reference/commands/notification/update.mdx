# Update

Pass settings as JSON via --json. Example: coolify notification update webhook --json '&#123;"webhook_enabled":true&#125;'

## Usage

```sh
coolify notification update <channel>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--json` | `string` | No | — | JSON object of fields to update |

## Get current help

```sh
coolify notification update --help
```

The installed CLI help reflects the exact options available in your CLI version.
