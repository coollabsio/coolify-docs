# Environments delete

Delete a project environment

## Usage

```sh
coolify project environments delete <project_uuid> <environment>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | No | `false` | Skip confirmation prompt |

## Get current help

```sh
coolify project environments delete --help
```

The installed CLI help reflects the exact options available in your CLI version.
