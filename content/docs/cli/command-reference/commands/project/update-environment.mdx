# Update environment

Update a project environment. Prefer: coolify project environments update

## Usage

```sh
coolify project update-environment <project_uuid> <environment>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | No | — | Environment description |
| `--name` | `string` | No | — | Environment name |

## Get current help

```sh
coolify project update-environment --help
```

The installed CLI help reflects the exact options available in your CLI version.
