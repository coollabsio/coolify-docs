# Environments create

Create an environment in a project

## Usage

```sh
coolify project environments create <project_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | Yes | — | Environment name (required) |

## Get current help

```sh
coolify project environments create --help
```

The installed CLI help reflects the exact options available in your CLI version.
