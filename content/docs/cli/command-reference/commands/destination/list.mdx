# List

List destinations

## Usage

```sh
coolify destination list
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--server` | `string` | No | — | Only destinations belonging to this server UUID |

## Get current help

```sh
coolify destination list --help
```

The installed CLI help reflects the exact options available in your CLI version.
