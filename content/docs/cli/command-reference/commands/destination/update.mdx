# Update

Rename a destination

## Usage

```sh
coolify destination update <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | No | — | New destination name |

## Get current help

```sh
coolify destination update --help
```

The installed CLI help reflects the exact options available in your CLI version.
