# Server create

Create server shared env

## Usage

```sh
coolify shared-env server create <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--comment` | `string` | No | — | Comment |
| `--key` | `string` | No | — | Variable key |
| `--literal` | `boolean` | No | `false` | Treat value as literal |
| `--multiline` | `boolean` | No | `false` | Multiline value |
| `--shown-once` | `boolean` | No | `false` | Show value only once |
| `--value` | `string` | No | — | Variable value |

coolify shared-env server create --help
