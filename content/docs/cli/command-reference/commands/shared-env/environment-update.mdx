# Environment update

Update environment shared env

## Usage

```sh
coolify shared-env environment update <project_uuid> <environment> <id>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--comment` | `string` | No | — | Comment |
| `--key` | `string` | No | — | Variable key |
| `--literal` | `boolean` | No | `false` | Treat value as literal |
| `--multiline` | `boolean` | No | `false` | Multiline value |
| `--shown-once` | `boolean` | No | `false` | Show value only once |
| `--value` | `string` | No | — | Variable value |

## Get current help

```sh
coolify shared-env environment update --help
```

The installed CLI help reflects the exact options available in your CLI version.
