# Cancel

Cancel an in-progress deployment. This will stop the deployment process and clean up any temporary resources.

## Usage

```sh
coolify deploy cancel <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | No | `false` | Skip confirmation prompt |

## Get current help

```sh
coolify deploy cancel --help
```

The installed CLI help reflects the exact options available in your CLI version.
