# Enable

Enable the Coolify MCP server (API: POST /mcp/enable). Requires a root team API token.

## Usage

```sh
coolify mcp enable
```

## Get current help

```sh
coolify mcp enable --help
```

The installed CLI help reflects the exact options available in your CLI version.
