# Disable

Disable the Coolify MCP server (API: POST /mcp/disable). Requires a root team API token.

## Usage

```sh
coolify mcp disable
```

## Get current help

```sh
coolify mcp disable --help
```

The installed CLI help reflects the exact options available in your CLI version.
