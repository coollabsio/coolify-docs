# Traffic

Get application traffic analytics

## Usage

```sh
coolify app traffic <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--range` | `string` | No | `24h` | Time range: 24h, 7d, 30d |

## Get current help

```sh
coolify app traffic --help
```

The installed CLI help reflects the exact options available in your CLI version.
