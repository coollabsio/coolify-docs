# Secret manager set

Set the secret manager source of an application

## Usage

```sh
coolify app secret-manager set <app_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--integration-token` | `string` | Yes | — | UUID of the secret manager integration token (required) |
| `--settings` | `string` | No | — | Provider settings as a JSON object |

## Get current help

```sh
coolify app secret-manager set --help
```

The installed CLI help reflects the exact options available in your CLI version.
