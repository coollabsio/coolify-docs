# Previews get

Get a preview deployment of an application by pull request ID.

## Usage

```sh
coolify app previews get <app_uuid> <pr_id>
```

## Get current help

```sh
coolify app previews get --help
```

The installed CLI help reflects the exact options available in your CLI version.
