# Env delete

Delete an environment variable from an application. First UUID is the application, second is the specific environment variable to delete.

## Usage

```sh
coolify app env delete <app_uuid> <env_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | No | `false` | Skip confirmation prompt |

## Get current help

```sh
coolify app env delete --help
```

The installed CLI help reflects the exact options available in your CLI version.
