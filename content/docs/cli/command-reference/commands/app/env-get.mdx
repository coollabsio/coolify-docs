# Env get

Get detailed information about a specific environment variable by UUID or key name.

## Usage

```sh
coolify app env get <app_uuid> <env_uuid_or_key>
```

## Get current help

```sh
coolify app env get --help
```

The installed CLI help reflects the exact options available in your CLI version.
