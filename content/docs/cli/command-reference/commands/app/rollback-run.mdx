# Rollback run

Rollback application to a commit

## Usage

```sh
coolify app rollback run <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--commit` | `string` | No | — | Git commit SHA |

## Get current help

```sh
coolify app rollback run --help
```

The installed CLI help reflects the exact options available in your CLI version.
