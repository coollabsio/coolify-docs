# Start

Start an application (initiates a deployment).

## Usage

```sh
coolify app start <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force` | `boolean` | No | `false` | Force rebuild |
| `--instant-deploy` | `boolean` | No | `false` | Instant deploy (skip queuing) |

## Get current help

```sh
coolify app start --help
```

The installed CLI help reflects the exact options available in your CLI version.
