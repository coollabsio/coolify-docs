# Env get

Get detailed information about a specific environment variable. First UUID is the database, second is the environment variable UUID or key name.

## Usage

```sh
coolify database env get <database_uuid> <env_uuid_or_key>
```

## Get current help

```sh
coolify database env get --help
```

The installed CLI help reflects the exact options available in your CLI version.
