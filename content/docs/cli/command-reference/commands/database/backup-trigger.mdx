# Backup trigger

Trigger an immediate backup for a specific backup configuration. First UUID is the database, second is the specific backup configuration to trigger.

## Usage

```sh
coolify database backup trigger <database_uuid> <backup_uuid>
```

## Get current help

```sh
coolify database backup trigger --help
```

The installed CLI help reflects the exact options available in your CLI version.
