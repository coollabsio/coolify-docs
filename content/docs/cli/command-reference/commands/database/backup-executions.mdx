# Backup executions

List all executions for a backup configuration. First UUID is the database, second is the specific backup configuration.

## Usage

```sh
coolify database backup executions <database_uuid> <backup_uuid>
```

## Get current help

```sh
coolify database backup executions --help
```

The installed CLI help reflects the exact options available in your CLI version.
