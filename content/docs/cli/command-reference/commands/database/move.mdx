# Move

Move a database to another environment

## Usage

```sh
coolify database move <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--environment-uuid` | `string` | Yes | — | Target environment UUID (required) |

## Get current help

```sh
coolify database move --help
```

The installed CLI help reflects the exact options available in your CLI version.
