# Import upload

Upload a local backup file (max 10 GiB) in chunks. Prints the upload ID to pass to 'start --upload-id'.

## Usage

```sh
coolify database import upload <database_uuid> <file>
```

## Get current help

```sh
coolify database import upload --help
```

The installed CLI help reflects the exact options available in your CLI version.
