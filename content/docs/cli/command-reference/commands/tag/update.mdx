# Update

Rename a team tag

## Usage

```sh
coolify tag update <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | No | — | New tag name |

## Get current help

```sh
coolify tag update --help
```

The installed CLI help reflects the exact options available in your CLI version.
