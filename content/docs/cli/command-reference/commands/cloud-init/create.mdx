# Create

Create a cloud-init script

## Usage

```sh
coolify cloud-init create
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | No | — | Script name |
| `--script` | `string` | No | — | Script contents |
| `--script-file` | `string` | No | — | Read script contents from file |

## Get current help

```sh
coolify cloud-init create --help
```

The installed CLI help reflects the exact options available in your CLI version.
