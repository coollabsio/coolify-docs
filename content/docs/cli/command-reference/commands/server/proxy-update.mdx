# Proxy update

Update proxy settings

## Usage

```sh
coolify server proxy update <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--generate-exact-labels` | `boolean` | No | `false` | Generate exact labels |
| `--proxy-type` | `string` | No | — | Proxy type (e.g. TRAEFIK) |
| `--redirect-enabled` | `boolean` | No | `true` | Enable proxy redirect |
| `--redirect-url` | `string` | No | — | Redirect URL |

## Get current help

```sh
coolify server proxy update --help
```

The installed CLI help reflects the exact options available in your CLI version.
