# Hetzner create

Create a Hetzner server

## Usage

```sh
coolify server hetzner create
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--cloud-init` | `string` | No | — | Cloud-init YAML |
| `--cloud-token` | `string` | No | — | Cloud provider token UUID |
| `--enable-backups` | `boolean` | No | `false` | Enable Hetzner backups |
| `--enable-ipv4` | `boolean` | No | `true` | Enable public IPv4 |
| `--enable-ipv6` | `boolean` | No | `true` | Enable public IPv6 |
| `--firewall-ids` | `intSlice` | No | — | Hetzner firewall IDs |
| `--image` | `integer` | No | `0` | Hetzner image ID |
| `--location` | `string` | No | — | Hetzner location name |
| `--name` | `string` | No | — | Server name (auto-generated if omitted) |
| `--network-ids` | `intSlice` | No | — | Hetzner network IDs |
| `--private-key` | `string` | No | — | Coolify private key UUID |
| `--server-type` | `string` | No | — | Hetzner server type |
| `--ssh-key-ids` | `intSlice` | No | — | Additional Hetzner SSH key IDs |
| `--validate` | `boolean` | No | `false` | Validate after creation |

coolify server hetzner create --help
