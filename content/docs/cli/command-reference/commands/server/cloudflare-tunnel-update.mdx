# Cloudflare tunnel update

Set Cloudflare tunnel enabled state

## Usage

```sh
coolify server cloudflare-tunnel update <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--enabled` | `boolean` | Yes | `false` | Enable (true) or disable (false) Cloudflare tunnel |

## Get current help

```sh
coolify server cloudflare-tunnel update --help
```

The installed CLI help reflects the exact options available in your CLI version.
