# Cloudflare tunnel enable

Enable Cloudflare tunnel flag

## Usage

```sh
coolify server cloudflare-tunnel enable <server_uuid>
```

## Get current help

```sh
coolify server cloudflare-tunnel enable --help
```

The installed CLI help reflects the exact options available in your CLI version.
