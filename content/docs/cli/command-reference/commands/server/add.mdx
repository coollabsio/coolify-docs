# Add

Add a server

## Usage

```sh
coolify server add <server_name> <ip_address> <private_key_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--port (-p)` | `integer` | No | `22` | Port |
| `--user (-u)` | `string` | No | `root` | User |
| `--validate` | `boolean` | No | `false` | Validate the server |

## Get current help

```sh
coolify server add --help
```

The installed CLI help reflects the exact options available in your CLI version.
