# Cloudflare tunnel disable

Disable Cloudflare tunnel flag

## Usage

```sh
coolify server cloudflare-tunnel disable <server_uuid>
```

## Get current help

```sh
coolify server cloudflare-tunnel disable --help
```

The installed CLI help reflects the exact options available in your CLI version.
