# Remove

Remove a server

## Usage

```sh
coolify server remove <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-from-provider` | `boolean` | No | `false` | Also delete the server from its cloud provider (Hetzner, Vultr or DigitalOcean). This cannot be undone |
| `--force` | `boolean` | No | `false` | Also delete all resources on the server |

## Get current help

```sh
coolify server remove --help
```

The installed CLI help reflects the exact options available in your CLI version.
