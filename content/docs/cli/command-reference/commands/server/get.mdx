# Get

Get server details by uuid

## Usage

```sh
coolify server get <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--resources` | `boolean` | No | `false` | Show the resources deployed on the server instead of the server details |

## Get current help

```sh
coolify server get --help
```

The installed CLI help reflects the exact options available in your CLI version.
