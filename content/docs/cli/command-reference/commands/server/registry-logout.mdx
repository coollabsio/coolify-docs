# Registry logout

Log out from a Docker registry on a server

## Usage

```sh
coolify server registry logout <server_uuid> <registry>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | No | `false` | Skip confirmation prompt |

## Get current help

```sh
coolify server registry logout --help
```

The installed CLI help reflects the exact options available in your CLI version.
