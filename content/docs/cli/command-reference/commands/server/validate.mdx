# Validate

Validate a server

## Usage

```sh
coolify server validate <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--install` | `boolean` | No | `false` | Install missing prerequisites and Docker (may restart Docker) |

## Get current help

```sh
coolify server validate --help
```

The installed CLI help reflects the exact options available in your CLI version.
