# Destinations create

Create a server destination

## Usage

```sh
coolify server destinations create <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | No | — | Destination name |
| `--network` | `string` | Yes | — | Docker network name (required) |
| `--type` | `string` | No | — | Destination type: standalone or swarm |

## Get current help

```sh
coolify server destinations create --help
```

The installed CLI help reflects the exact options available in your CLI version.
