# Sentinel update

Update Sentinel settings via JSON

## Usage

```sh
coolify server sentinel update <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--json` | `string` | No | — | JSON fields to patch |

## Get current help

```sh
coolify server sentinel update --help
```

The installed CLI help reflects the exact options available in your CLI version.
