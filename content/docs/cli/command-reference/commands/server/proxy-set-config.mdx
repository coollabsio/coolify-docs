# Proxy set config

Save raw proxy configuration

## Usage

```sh
coolify server proxy set-config <server_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--configuration` | `string` | No | — | Raw proxy configuration |
| `--configuration-file` | `string` | No | — | Read configuration from file |

## Get current help

```sh
coolify server proxy set-config --help
```

The installed CLI help reflects the exact options available in your CLI version.
