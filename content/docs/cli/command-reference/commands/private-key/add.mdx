# Add

Add a private key

## Usage

```sh
coolify private-key add <key_name> <private_key_or_file>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | No | — | Private key description |

## Get current help

```sh
coolify private-key add --help
```

The installed CLI help reflects the exact options available in your CLI version.
