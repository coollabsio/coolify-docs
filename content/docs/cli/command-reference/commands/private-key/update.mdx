# Update

Update a private key

## Usage

```sh
coolify private-key update <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--description` | `string` | No | — | Private key description |
| `--name` | `string` | No | — | Private key name |
| `--private-key` | `string` | Yes | — | Private key content or path to key file (required) |

## Get current help

```sh
coolify private-key update --help
```

The installed CLI help reflects the exact options available in your CLI version.
