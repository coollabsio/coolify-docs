# Delete

Delete a GitHub App integration. The app must not be used by any applications.

## Usage

```sh
coolify github delete <app_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--force (-f)` | `boolean` | No | `false` | Skip confirmation prompt |

## Get current help

```sh
coolify github delete --help
```

The installed CLI help reflects the exact options available in your CLI version.
