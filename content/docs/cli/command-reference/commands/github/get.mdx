# Get

Get detailed information about a specific GitHub App integration. Accepts the app UUID (numeric ID also accepted).

## Usage

```sh
coolify github get <app_uuid>
```

## Get current help

```sh
coolify github get --help
```

The installed CLI help reflects the exact options available in your CLI version.
