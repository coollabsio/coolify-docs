# Update

Update settings of the team bound to the API token

## Usage

```sh
coolify teams update
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--build-server-fallback` | `boolean` | Yes | `false` | Allow deployments to fall back to the deployment server when no build server is usable (required) |

## Get current help

```sh
coolify teams update --help
```

The installed CLI help reflects the exact options available in your CLI version.
