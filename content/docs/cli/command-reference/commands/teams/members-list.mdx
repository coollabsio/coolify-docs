# Members list

List members of a specific team by ID, or list members of the current team if no ID is provided.

## Usage

```sh
coolify teams members list [team_id]
```

## Get current help

```sh
coolify teams members list --help
```

The installed CLI help reflects the exact options available in your CLI version.
