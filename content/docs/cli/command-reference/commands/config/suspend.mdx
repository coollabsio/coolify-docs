# Suspend

Pause the sync of a coolify.json link. Paused resources can be edited in Coolify again. Only a team admin can pause.

## Usage

```sh
coolify config suspend <link_uuid>
```

## Get current help

```sh
coolify config suspend --help
```

The installed CLI help reflects the exact options available in your CLI version.
