# Link update

Change auto apply or the server of a coolify.json link

## Usage

```sh
coolify config link update <link_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--auto-apply` | `boolean` | No | `false` | Apply safe changes automatically |
| `--destination-uuid` | `string` | No | — | Destination on the new server, when it has more than one |
| `--server-uuid` | `string` | No | — | New default server of the link |

## Get current help

```sh
coolify config link update --help
```

The installed CLI help reflects the exact options available in your CLI version.
