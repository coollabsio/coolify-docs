# Export

Export an environment as a coolify.json file

## Usage

```sh
coolify config export <environment_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--output (-o)` | `string` | No | — | Write the file to this path instead of standard output |

## Get current help

```sh
coolify config export --help
```

The installed CLI help reflects the exact options available in your CLI version.
