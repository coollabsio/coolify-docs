# Approve

Approve a revision that waits for approval

## Usage

```sh
coolify config approve <revision_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--delete-data` | `stringSlice` | No | — | Key of a removed resource whose data is deleted too (repeatable) |
| `--force (-f)` | `boolean` | No | `false` | Skip confirmation prompt for --delete-data |

## Get current help

```sh
coolify config approve --help
```

The installed CLI help reflects the exact options available in your CLI version.
