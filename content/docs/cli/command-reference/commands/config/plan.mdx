# Plan

Compare a coolify.json file with an environment

## Usage

```sh
coolify config plan <environment_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--file (-f)` | `string` | No | `coolify.json` | Path to the coolify.json file (- reads standard input) |

## Get current help

```sh
coolify config plan --help
```

The installed CLI help reflects the exact options available in your CLI version.
