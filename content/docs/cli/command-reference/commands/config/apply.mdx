# Apply

Plan and apply coolify.json

## Usage

```sh
coolify config apply <link_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--file (-f)` | `string` | No | `coolify.json` | Path to the coolify.json file for an api link (- reads standard input) |

## Get current help

```sh
coolify config apply --help
```

The installed CLI help reflects the exact options available in your CLI version.
