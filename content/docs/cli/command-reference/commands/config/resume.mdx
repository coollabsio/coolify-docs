# Resume

Resume the sync of a coolify.json link

## Usage

```sh
coolify config resume <link_uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--confirm` | `boolean` | No | `false` | Resume and apply the file |

## Get current help

```sh
coolify config resume --help
```

The installed CLI help reflects the exact options available in your CLI version.
