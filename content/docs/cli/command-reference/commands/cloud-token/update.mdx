# Update

Rename a cloud provider token

## Usage

```sh
coolify cloud-token update <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--name` | `string` | No | — | New friendly token name |

## Get current help

```sh
coolify cloud-token update --help
```

The installed CLI help reflects the exact options available in your CLI version.
