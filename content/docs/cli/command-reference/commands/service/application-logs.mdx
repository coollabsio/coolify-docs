# Application logs

Get logs for an application in a service

## Usage

```sh
coolify service application logs <service-uuid> <application-uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--lines (-n)` | `integer` | No | `100` | Number of log lines to retrieve |

## Get current help

```sh
coolify service application logs --help
```

The installed CLI help reflects the exact options available in your CLI version.
