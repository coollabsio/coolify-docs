# Env get

Get detailed information about a specific environment variable. First UUID is the service, second is the environment variable UUID or key name.

## Usage

```sh
coolify service env get <service_uuid> <env_uuid_or_key>
```

## Get current help

```sh
coolify service env get --help
```

The installed CLI help reflects the exact options available in your CLI version.
