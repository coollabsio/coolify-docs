# Logs

Get logs for a service sub-resource

## Usage

```sh
coolify service logs <uuid>
```

## Options

| Option | Type | Required | Default | Description |
| :--- | :--- | :---: | :--- | :--- |
| `--lines (-n)` | `integer` | No | `100` | Number of log lines to retrieve |
| `--show-timestamps` | `boolean` | No | `false` | Include timestamps in logs |
| `--sub-service-name` | `string` | Yes | — | Sub-service name from the service applications or databases list (required) |

## Get current help

```sh
coolify service logs --help
```

The installed CLI help reflects the exact options available in your CLI version.
