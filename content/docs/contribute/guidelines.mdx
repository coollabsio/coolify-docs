# Contributing to Coolify

We are happy that you are interested in contributing to Coolify.

<ContributionGuidelinesPage>

<CoolCallout icon={ArrowsRight} title="The short version">

Coolify is used by 470K+ people and maintained by two core maintainers. Contributions are welcome, but alignment matters more than volume: keep changes focused, discuss larger work before coding, test what you submit, and target the `next` branch.

</CoolCallout>

<CoolCallout icon={Warning22} title="Important" type="warn">

These guidelines are stricter than many open-source projects on purpose. Clear structure and boundaries reduce maintainer burnout and keep Coolify sustainable long term.

</CoolCallout>

<CoolCallout icon={Checklist2} title="Commit and pull request format" contentClassName="!p-0">
<CoolPanel>

Commit messages and pull request titles should start with an action and category. Keep descriptions concise; walls of text listing every small change may be rejected.

</CoolPanel>
<CoolPanel withDivider>

| Prefix | Use |
| :--- | :--- |
| fix(ui): | UI-related fixes |
| fix(api): | API-related fixes |
| feat(api): | API-related additions |
| feat(service): | One-click service changes |

</CoolPanel>
</CoolCallout>

<CoolCallout icon={MagicWand} title="AI usage">

AI tools are allowed, but you must disclose AI usage in the pull request description. You are still responsible for understanding every change, verifying correctness, and following existing project patterns.

</CoolCallout>

<CoolCallout icon={MessageQuestion2} title="FAQ" contentClassName="!p-0">
<CoolAccordions>
<Accordion title="Should I ask before fixing a typo or small bug?">

No. Small, obvious fixes can be submitted directly as a pull request.

</Accordion>
<Accordion title="Can I open a pull request for a new feature?">

Discuss it first in GitHub Discussions or Discord. New features without prior alignment may be closed without review.

</Accordion>
<Accordion title="Can I work on an open issue?">

Comment first to confirm the issue is still relevant and that no one else is actively working on it.

</Accordion>
<Accordion title="Can I clean up code while fixing something else?">

Keep the pull request focused on the stated goal. Refactors and cleanup work should be discussed and submitted separately.

</Accordion>
<Accordion title="Can I use AI to help?">

Yes, but disclose it in the pull request description. You must understand, verify, and own every change.

</Accordion>
<Accordion title="Why was my pull request closed without detailed feedback?">

It usually means the change did not align with project direction, required too much review capacity, or targeted work that is not planned.

</Accordion>
</CoolAccordions>
