# Coolify Docs Contribution Guide

Contribute updates and fixes to the Coolify documentation with the same workflow and review expectations as other Coolify contributions.

<CoolDocsPage hideToc>

<CoolCallout icon={ArrowsRight} title="The short version">

Fork [coollabsio/coolify-docs](https://github.com/coollabsio/coolify-docs), work from the `next` branch, run the docs locally with Bun, and open focused pull requests back to `next`.

</CoolCallout>

---

<CoolCallout icon={BrowserTerminal} title="Local development">

Install dependencies and start the documentation site from the repository root.

```bash
bun install
bun run dev
```

The development server starts at [http://localhost:5173/docs/](http://localhost:5173/docs/).

</CoolCallout>

<CoolCallout icon={Warning22} title="Package manager note" type="warn">

Bun is the expected package manager. If you use another tool locally, do not commit its lockfile or configuration files.

</CoolCallout>

---

<CoolCallout icon={DocumentText2} title="Writing and structure">

- Use clear, simple English for readers who may not be native English speakers.
- Break guides into small steps that a new self-hoster can follow without guessing.
- Add screenshots when they help explain a screen, setting, or expected result.
- Use existing docs components and nearby pages as the pattern before creating anything new.

</CoolCallout>

---

<CoolCallout icon={Image} title="Images and screenshots" contentClassName="!p-0">
<CoolPanel>

Screenshots should make a step easier to follow, not decorate the page.

</CoolPanel>
<CoolPanel withDivider>

| Rule | Expectation |
| :--- | :--- |
| Format | Use .webp images for documentation screenshots and illustrations. |
| Location | Place image files in `public/images/...`, then reference them from MDX as `/images/...`. |
| Component | Use the zoomable image component to add images to docs. |

</CoolPanel>
<CoolPanel withDivider>

Use this component for docs screenshots:

```tsx
<ZoomableImage src="/images/path-to-the-image.webp" alt="Describe the image" />
```

Example:

```tsx
<ZoomableImage src="/images/applications/domain.webp" alt="Application domain settings" />
```

</CoolPanel>
</CoolCallout>

<CoolCallout icon={MessageQuestion2} title="FAQ" contentClassName="!p-0">
<CoolAccordions>
<Accordion title="Can I fix a typo directly?">

Yes. Small, obvious documentation fixes can be opened as a pull request without prior discussion.

</Accordion>
<Accordion title="Should I target main or next?">

Target next. The main branch represents production, while next is the development branch.

</Accordion>
<Accordion title="Can I use npm, pnpm, or yarn locally?">

You can use a different package manager locally, but do not include its generated files in your commit.

</Accordion>
<Accordion title="Where should I ask questions?">

Open an issue for repository-specific problems, or ask in the contribute channel on Discord.

</Accordion>
</CoolAccordions>
</CoolCallout>
