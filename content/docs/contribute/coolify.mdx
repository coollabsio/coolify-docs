# Contributing to Coolify

Set up the local Coolify development environment and prepare code contributions for the core repository.

<CoolDocsPage hideToc>

<CoolCallout icon={ArrowsRight} title="The short version">

Set up Docker, Spin, and a local fork of [coollabsio/coolify](https://github.com/coollabsio/coolify). Start the stack with `spin up`, test at **http://localhost:8000**, and open pull requests against the `next` branch.

</CoolCallout>

---

<CoolCallout icon={Monitor} title="Setup development environment" contentClassName="!p-0">
<CoolAccordions>
<Accordion title="Windows">

Use WSL2 with Docker CE for the closest Linux development experience.

- Install [WSL2](https://learn.microsoft.com/en-us/windows/wsl/install?ref=coolify) with a Linux distribution such as Ubuntu.
- Install [Docker Engine](https://docs.docker.com/engine/install/?ref=coolify) inside WSL2, or use [Docker Desktop](https://docs.docker.com/desktop/install/windows-install/?ref=coolify) with the WSL2 backend enabled.
- Install [Spin for Windows](https://serversideup.net/open-source/spin/docs/installation/install-windows#download-and-install-spin-into-wsl2?ref=coolify).

</Accordion>
<Accordion title="macOS">

OrbStack is recommended because it is lighter than Docker Desktop for local development.

- Install [OrbStack](https://docs.orbstack.dev/quick-start#installation?ref=coolify) or [Docker Desktop for Mac](https://docs.docker.com/desktop/install/mac-install/?ref=coolify).
- Install [Spin for macOS](https://serversideup.net/open-source/spin/docs/installation/install-macos/#download-and-install-spin?ref=coolify).
- If permission errors appear when starting the stack, try running Spin with sudo.

</Accordion>
<Accordion title="Linux">

Docker Engine is recommended because it avoids the extra VM layer.

- Install [Docker Engine](https://docs.docker.com/engine/install/?ref=coolify) for your distribution, or use [Docker Desktop for Linux](https://docs.docker.com/desktop/install/linux-install/?ref=coolify) if you want a GUI.
- Install [Spin for Linux](https://serversideup.net/open-source/spin/docs/installation/install-linux#configure-docker-permissions?ref=coolify).
- Make sure your user can run Docker commands without restarting the setup flow repeatedly.

</Accordion>
</CoolAccordions>
</CoolCallout>

<CoolCallout icon={Rocket} title="Start Coolify">

Open a terminal in the local Coolify repository and leave the process running.

```bash
spin up
```

If you hit permission errors, especially on macOS, run:

```bash
sudo spin up
```

</CoolCallout>

<CoolCallout icon={Warning22} title="Startup note" type="warn">

You may see some errors during startup. That can be expected while the development stack is booting.

</CoolCallout>

<CoolCallout icon={Settings} title="Enable Telescope">

Telescope is disabled by default. Add this to your `.env` file when you need the debugging dashboard.

```bash
TELESCOPE_ENABLED=true
```

</CoolCallout>

---

<CoolCallout icon={Clipboard} title="Create a pull request">

- Commit and push your changes to your fork.
- Open the pull request against the Coolify repository.
- Set the base branch to `next`, not `v4.x`.
- Manually test the changed flow in the local app, not only through test files.
- Fill in the pull request template with the details maintainers need.
- Move the pull request out of draft as soon as it is ready for review.

</CoolCallout>

<CoolCallout icon={Warning22} title="Draft pull requests" type="warn">

Pull requests that stay in draft for a long time may be closed by maintainers.

</CoolCallout>

<CoolCallout icon={Database} title="Development notes">

Run migrations after switching branches, pulling updates, or changing database structure.

```bash
docker exec -it coolify php artisan migrate
```

To reset the development database with default seed data, run:

```bash
docker exec -it coolify php artisan migrate:fresh --seed
```

</CoolCallout>

---

<CoolCallout icon={Warning22} title="Reset development environment" type="warn">

If the local stack or database is broken, remove the development containers and volumes, then start from a clean slate.

<Steps>
<Step>

**Stop the running Spin process**

Press Ctrl+C in the terminal where Spin is running.

</Step>
<Step>

**Remove development containers**

```bash
docker rm coolify coolify-db coolify-redis coolify-realtime coolify-testing-host coolify-minio coolify-vite-1 coolify-mail
```

</Step>
<Step>

**Remove development volumes**

```bash
docker volume rm coolify_dev_backups_data coolify_dev_postgres_data coolify_dev_coolify_data coolify_dev_minio_data
```

If your volume names do not use the `coolify` prefix, remove the prefix from the volume command before running it.

</Step>
<Step>

**Remove unused images**

```bash
docker image prune -a
```

</Step>
<Step>

**Start Coolify again**

```bash
spin up
```

</Step>
<Step>

**Run migrations and seeders**

```bash
docker exec -it coolify php artisan migrate:fresh --seed
```

</Step>
</Steps>

</CoolCallout>
