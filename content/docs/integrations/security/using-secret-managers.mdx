# Use a secret manager

Secret managers work with applications, Docker Compose services, and standalone databases. Application support includes Git and non-Git deployment methods.

1. Add a supported provider under **Keys & Tokens > Integration Tokens**.
2. Open the resource and select **Configuration > Environment Variables**.
3. Under **Secret manager**, choose the integration token and its project, environment, config, mount, or path.
4. Browse or import keys, or add a variable manually with this value:

   ```dotenv
   API_KEY={{vault.API_KEY}}
   ```

5. Deploy or restart the resource.

Always use `{{vault.KEY}}`, regardless of whether the provider is Doppler, Infisical, or HashiCorp Vault.

Coolify fetches values during deployment or startup. Values are held in memory and passed to the resource; Coolify does not save the fetched values in its database. A missing source or key stops the operation.

## Refresh a changed secret

Redeploy or restart the resource after changing a provider value. For application build variables, use a deployment rather than restart. Coolify includes resolved build values in cache invalidation so a changed remote value rebuilds affected layers.

<Callout type="info" title="One source per resource">

Each resource can link one secret-manager source. A Service-level source applies to the whole Compose stack.

</Callout>

If you have not created credentials yet, follow [Secret manager credentials](/integrations/security/secret-managers).
