# Overview

Coolify MCP exposes tools, resources, and prompts for the team associated with the API token.

## Start with these tools

| Tool | Use |
| :--- | :--- |
| `coolify_help` | Find a tool by intent. |
| `get_infrastructure_overview` | Get counts and health hints for the team. |
| `search_resources` | Find a resource by name, UUID, or domain when its type is unknown. |
| `list_unhealthy_resources` | Find resources that appear unhealthy or down. |

## Create and change resources

Creation and management tools accept an `action`, resource identifiers, and a `data` object containing the related REST API request fields. For example, `manage_project` can create a project:

```json
{
  "action": "create",
  "data": { "name": "storefront", "description": "Production storefront" }
}
```

Use `coolify_help` to discover the tools available to the current token and recipes such as `deploy_app_from_git` and `add_database_to_app`. Only permitted tools and actions are advertised.

Resource changes generally require `write`; deploying requires `deploy`. Some operations need both. Actions that require confirmation reject the request until `confirm=true` is supplied. Review the change before confirming it; see [MCP security](/mcp/security).
