# Overview

Coolify MCP exposes tools, resources, and prompts for the team associated with the API token. MCP lists only the tools that the token's permissions allow. `coolify_help` shows these tools and step-by-step recipes, for example `topic=deploy_app_from_git`.

## Start with these tools

| Tool | Use |
| :--- | :--- |
| `coolify_help` | Find a tool by intent. |
| `get_infrastructure_overview` | Get counts and health hints for the team. |
| `search_resources` | Find a resource by name, UUID, or domain when its type is unknown. |
| `list_unhealthy_resources` | Find resources that appear unhealthy or down. |

## Permissions

| Permission | Tools |
| :--- | :--- |
| `read` | `list_*` and `get_*` tools, and read actions of `manage_*` tools. |
| `read:sensitive` | Logs, environment values, command bodies, and other sensitive fields. |
| `deploy` | `deploy`, `control`, `cancel_deployment`, `rollback_application`, and actions that run or delete workloads. |
| `write` | `create_*` and `manage_*` tools. They use the same REST API routes, validation, and permissions as the API. |

Destructive actions need `confirm=true`. Your client must ask you before it sends it.

Most list tools return paginated data. Read [Pagination](/mcp/capabilities/pagination) before iterating through large results.
