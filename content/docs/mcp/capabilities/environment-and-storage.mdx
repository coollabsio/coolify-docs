# Environment and storage

| Tool | Permission | Purpose |
| :--- | :--- | :--- |
| `list_env_keys` | `read` | List environment-variable key names for an application, database, or service. Never returns values. |
| `list_shared_env_keys` | `read` | List shared key names at project or environment scope. Never returns values. |
| `list_storages` | `read` | List persistent and file storage mounts. Never returns file contents. |
| `get_env_values` | `read` + `read:sensitive` | Read environment values for an application, database, service, or shared-variable scope. Requires an Admin or Owner role; locked values remain hidden. |
| `manage_env` | `write` | Create, update, bulk update, or delete application, database, or service variables. |
| `manage_shared_env` | `write` | Manage shared variables at team, project, environment, or server scope. |
| `manage_storage` | `write` | Manage persistent/file mounts and configure, remove, or run their volume backup schedules. |

The key-listing tools return names only. `get_env_values` supports application, database, service, team, project, environment, and server scopes. Management responses reveal supported values only with `read:sensitive`; locked values stay hidden.

Storage creation and updates can write file content. Deleting a mount or removing its backup schedule requires `confirm=true`; removing a backup schedule deletes its local and S3 archives. Running a volume backup also requires confirmation because its schedule may stop the resource.
