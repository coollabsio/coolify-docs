# Integrations

| Tool | Purpose |
| :--- | :--- |
| `list_github_apps` | List GitHub Apps available to the team without returning secrets. |
| `list_github_repositories` | List repositories through a team GitHub App. |
| `list_github_branches` | List branches for a repository through a team GitHub App. |

Repository and branch tools register only when a GitHub App exists on the instance. Call `list_github_apps` first.

## Manage Git sources and S3 storages

| Tool | Actions |
| :--- | :--- |
| `manage_git_source` | GitHub and GitLab apps. `list` (`read`); `create`, `update` (`write`); `delete` (`write`, confirm). |
| `manage_s3_storage` | `list`, `get` (`read`); `create`, `update`, `validate` (`write`); `delete` (`write`, confirm). Secrets are never returned. |

Actions marked **confirm** need `confirm=true`. Ask the user before your client sends it.
