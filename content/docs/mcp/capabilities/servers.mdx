# Servers

| Tool | Purpose |
| :--- | :--- |
| `list_servers` | List team-visible servers; optionally filter by reachability. |
| `get_server` | Inspect one server by UUID. Sensitive connection fields remain redacted. |
| `get_server_domains` | List domains hosted on a server. |
| `get_server_resources` | List resources defined on a server. |
| `list_destinations` | List Docker destinations; optionally filter by server. |
| `get_destination` | Inspect one Docker destination by UUID. |
| `get_server_metrics` | Read current and recent Sentinel CPU, memory, disk, load, and network metrics. Requires `read` and metrics enabled on the server. |
| `manage_server` | Add, update, delete, or validate servers. Requires `write`. |
| `manage_proxy` | Read settings with `read` or change/restart the proxy with `write`. Configuration-file output also needs `read:sensitive`. |
| `docker_cleanup` | Run server Docker cleanup. Requires `write` and `confirm=true`. |
| `manage_destination` | Create/update/delete Docker destinations. Requires `write`. |
| `manage_registry` | List registry logins with `read:sensitive`, or add/check/remove them with `write`. Passwords are never returned. |

Use `get_infrastructure_overview` first for counts and server health hints.
