# MCP overview

Coolify MCP connects compatible AI clients to your Coolify instance over Streamable HTTP. Read the pages below in order to learn how MCP works, set it up, and connect a client.

## Start here

1. Read [What is MCP?](/mcp/what-is-mcp) to understand tools, resources, prompts, and scope.
2. Read [How MCP works](/mcp/how-mcp-works) to understand authentication and team boundaries.
3. Follow [Set up MCP](/mcp/setup) to enable the endpoint and create a token.
4. Configure [Claude Code](/mcp/clients/claude-code), [Cursor](/mcp/clients/cursor), or [another MCP client](/mcp/clients/other-clients).

## Find capabilities

After connecting a client, use [MCP capabilities](/mcp/capabilities/overview) to find tools by task. Start with `coolify_help`, `get_infrastructure_overview`, or `search_resources`.
