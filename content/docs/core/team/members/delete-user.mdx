# Delete a user

Deleting a user removes the user account itself from a self-hosted Coolify instance. This is different from [removing a member](/core/team/members/remove-a-member), which only ends a person's membership in the active team while their account stays available.

<Callout type="warning" title="This can delete server resources">
If Coolify still has a working connection to the user's servers, deleting the user also deletes all resources on those servers, not only the records in Coolify's database.
</Callout>

## Before you delete a user

- You must be an **Owner** or **Admin** of the `root` team, which makes you an instance administrator.
- You cannot delete the `root` user, your own account, or a user with a higher role in the `root` team than yours. A user who is alone in the `root` team also cannot be deleted.
- Confirm which teams the user belongs to and what resources those teams own.

## Delete the user

1. Select **Team** in the Coolify sidebar, then select **Admin View**. The **Instance users** list shows every user except you.
2. Find the user, then select the trash icon (**Delete user**) in their row.
3. In the **Confirm User Deletion?** dialog, enter the user name and your password to confirm.

## What happens during deletion

Coolify revokes the API tokens of the user. Then it applies these rules to every team that the user belongs to:

### The user is alone in the team

The team and all of its resources are deleted from both the servers and Coolify's database.

### The user is not alone in the team

1. The user is an Owner, and another Owner or Admin is in the team:
   - The user is removed from the team. No resources are deleted.

2. The user is an Owner, and no other Owner or Admin is in the team:
   - The first person with the **Member** role becomes an Owner.
   - The user is removed from the team. No resources are deleted.

3. The user is an Admin or a Member:
   - The user is removed from the team. No resources are deleted. Ownership does not change.

## Delete your own account

Use [Profile and account deletion](/core/security/authentication/profile) to delete your own account. The team admin view does not let you delete your own account, the root user, or a user with a higher role in the root team. For example, a root team Admin cannot delete a root team Owner.
