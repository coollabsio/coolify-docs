# Manage tags

Create tags from the main **Tags** page, then connect them to resources. You can also create or assign tags from an application or service. Tags belong to the active team.

## Create a tag before assigning resources

1. Open **Tags** in the main sidebar.
2. Select **New tag**.
3. Enter a unique name of 2 to 255 characters without spaces, then select **Create tag**. Coolify stores the name in lowercase.

The new tag can remain empty until you assign resources.

## Connect resources from a tag

Open the tag and select **Connect to resources**. Resources are grouped by project and environment. Select a resource to assign the tag; clear its selection to remove the assignment. Each change is saved immediately. You need permission to update the resource.

On a wide screen, **Connect in canvas** opens a visual view of the assignments. Tags can connect to applications, services, and standalone databases. Bulk deployment by tag operates on applications and services.

## Add tags to a resource

<Steps>
<Step>

### Open the resource

Open the application or service you want to tag, then select **Tags**.

</Step>
<Step>

### Enter one or more names

In **Create new or assign existing tags**, enter a tag name. To add several tags at once, separate the names with spaces:

```txt
production storefront eu
```

Each name must contain at least two characters. Coolify removes HTML and stores the name in lowercase.

</Step>
<Step>

### Add the tags

Click **Add**. Newly created and reused tags appear under **Assigned Tags**.

</Step>
</Steps>

Open **Tags** in the main sidebar and select one of the assigned names. The resource should appear in that tag's details.

---

## Assign an existing tag

Tags from the active team that are not assigned to the resource appear under **Existing Tags**. Click a name to assign it without entering the name again.

The same tag can be assigned to applications and services in different projects or environments within the team.

---

## Remove a tag

Under **Assigned Tags**, click the remove icon beside the tag name. Coolify removes the tag from this resource immediately.

Removing a tag does not stop, restart, or redeploy the resource.

---

## Delete a tag

Removing the last assignment leaves the tag available for reuse. To remove the tag itself:

1. Open **Tags** and select the tag.
2. Select **Delete** and review the confirmation.
3. Enter the tag name and confirm deletion.

Deleting a tag removes its assignments from every resource. The resources keep running. Only team Owners and Admins can delete team tags.

---

## Troubleshooting

<Accordions type="multiple">
<Accordion title="Coolify reports an invalid tag">

Use a name with at least two characters. Separate multiple names with spaces instead of commas.

</Accordion>
<Accordion title="Coolify reports a duplicate tag">

The resource already has that tag. Check **Assigned Tags** instead of adding the same name again.

</Accordion>
<Accordion title="Tag controls are unavailable">

You need permission to update the resource before you can assign or remove tags. Ask a team administrator to update your role or make the change for you.

</Accordion>
</Accordions>
