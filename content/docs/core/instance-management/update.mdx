# Update Coolify

Updating Coolify changes the self-hosted Coolify control plane. It does not update the applications, databases, services, or servers you manage with Coolify.

<Callout type="warn" title="Coolify Cloud">
If you use **Coolify Cloud**, the Coolify team manages instance updates. You must wait for the Coolify team to update the instance.
</Callout>

For a self-hosted instance, open **Settings** in the left sidebar, choose **Configuration**, then select **Updates**.


## Before you update

- [Create an instance backup](/core/backup-and-recovery/instance-backup).
- Review the [release notes](https://github.com/coollabsio/coolify/releases) for the version you plan to install.
- Check for active deployments; they can fail during the update process.

## Automatic updates

Enable **Automatic updates** and set **Update frequency**. Coolify then checks for a new release and installs it automatically when one is available.

### Enable automatic updates

<ZoomableImage src="/docs/images/core/instance-management/update/automatic-updates-overview.webp" alt="Settings, Updates, and Automatic updates controls highlighted in sequence" />

Choose **Enabled** under **Automatic updates**. This option saves immediately, and **Update frequency** becomes available.

If automatic updates cannot be configured in the dashboard, `AUTOUPDATE` is set in `/data/coolify/source/.env`. Configure automatic updates in that file instead.

### Update frequency

<ZoomableImage src="/docs/images/core/instance-management/update/automatic-update-frequency.webp" alt="Update frequency field in Automatic updates settings" />

**Update frequency** sets how often Coolify checks for a new release and installs it if one is available. Enter a cron expression or a preset such as `every_minute`, `hourly`, `daily`, `weekly`, `monthly`, or `yearly`, then click **Save changes**. The default is `0 0 * * *`, which runs daily at midnight in the instance timezone.

During an update, Coolify restarts to apply the new version. The dashboard is unavailable briefly, usually for less than a minute.

**Update frequency is unavailable when `AUTOUPDATE` is set in `/data/coolify/source/.env`.**

---

### Check frequency

<ZoomableImage src="/docs/images/core/instance-management/update/automatic-update-check-frequency.webp" alt="Check frequency field and Check now button in Update checks" />

**Check frequency** sets how often Coolify checks the [versions file on the CDN](https://cdn.coollabs.io/coolify/versions.json) and updates the available-version status. Coolify installs an update only when a new version is available. Enter a cron expression or a preset such as `every_minute`, `hourly`, `daily`, `weekly`, `monthly`, or `yearly`, then click **Save changes**. The default is `0 * * * *`, which runs hourly.

Click **Check now** to check for a new version immediately. This does not install the update.

### Apply an available update

Use the dashboard when Coolify has found a newer version and you want to choose when to install it.

The **Upgrade** action appears in the sidebar only after Coolify has found a newer version.

Use **Check Manually** in **Settings > Configuration > Updates** to refresh that status first.

<Steps>
<Step>

**Choose a clear deployment window**

Confirm there are no active deployments before continuing.

</Step>
<Step>

**Open the upgrade dialog**

Click **Upgrade** in the left sidebar. Review the current and available version, then click **Upgrade Now**.

</Step>
<Step>

**Wait for Coolify to restart**

Keep the page open while Coolify shows progress.

The dashboard may briefly be unavailable while its services restart.

If the dashboard has not automatically reloaded after three minutes, refresh the page.

</Step>
<Step>

**Confirm the running version**

When the dashboard returns, confirm that the expected version is shown.

</Step>
</Steps>

</Tab>

### Run the installer over SSH

Use the installation script when you need to update over SSH or choose a specific version.

<Steps>
<Step>

**Connect to the Coolify server**

Connect to the server that runs the Coolify instance over SSH.

</Step>
<Step>

**Run the update command**

Use the latest-release command, or provide a version argument for a specific release.

Update to the latest release:

```sh
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

Update to a specific release:

```sh
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash -s <version>
```

Replace `<version>` with the Coolify version you want to install, for example `4.1.2`.

</Step>
<Step>

**Visit the dashboard**

Wait for the script to finish, then open the dashboard and confirm everything is working.

</Step>
</Steps>

</Tab>
</Tabs>

## Verify the update

After an update, confirm that the dashboard is reachable, the expected Coolify version is shown, and your resources are running.

If the dashboard does not return, review the update logs on the Coolify server. Coolify writes update logs under `/data/coolify/source/` with names such as `upgrade-2026-07-11-12-00-00.log`.
