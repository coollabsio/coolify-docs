# Vite

Vite is a build tool that aims to provide a faster and leaner development experience for modern web projects.

[Example repository.](https://github.com/coollabsio/coolify-examples/tree/main/javascript/build-tools/vite)

## Vanilla TypeScript build (Static)

- Set **Build strategy** to `nixpacks`.
- Choose **Static** in **Site type**.
- Set `Publish Directory` to `dist`.


## Vanilla JavaScript build (Static)

- Set **Build strategy** to `nixpacks`.
- Choose **Static** in **Site type**.
- Set `Publish Directory` to `dist`.
