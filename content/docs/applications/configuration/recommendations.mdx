# Recommendations

When Coolify recommends a setting for an application, the **General** page of the application shows a **Recommendations** section at the top. The section lists the settings that Coolify recommends and that the application does not use yet.

A yellow `!` next to **General** in the application settings sidebar shows that the application has open recommendations. Hold the pointer on the `!` to see how many, for example "2 recommendations". Under **General**, the **Recommendations** link goes to the section.

The section shows only when the application has an open or a dismissed recommendation. When there is no open recommendation, the sidebar shows no `!`.

## Recommendations

| Recommendation | Shown when | One-click fix |
| :--- | :--- | :--- |
| **Use build secrets** | The application builds with Dockerfile, Nixpacks, or Docker Compose, has at least one build-time variable, and uses standard build arguments. The recommendation is red when the application pushes its image to a registry. | **Turn on build secrets** sets [Build secrets](/applications/configuration/environment-variables#build-secrets) to **Docker BuildKit secrets**. |
| **Switch from Nixpacks to Railpack** | The application builds with Nixpacks, which is deprecated. | **Switch to Railpack** changes the build pack to [Railpack](/applications/builds/railpack) after a confirmation. You can switch back on the **General** page. |

A fix changes the setting only, then the page loads again. Redeploy the application to build it with the new setting.

<Callout type="warning" title="Check the build before you apply a fix">

With build secrets, build-time values are available only inside `RUN` instructions. Railpack reads `RAILPACK_*` variables and `railpack.json`, not `NIXPACKS_*` variables or `nixpacks.toml`. Check the deployment log after the next deployment.

</Callout>

## Dismiss a recommendation

Select **Dismiss** when a recommendation does not fit the application, for example when a Dockerfile must read a build-time variable in a `FROM` instruction. A dismissed recommendation does not show the `!` in the sidebar.

To see dismissed recommendations, select **Show dismissed** in the section header. Select **Restore** to show a recommendation again. When you dismissed every recommendation, the section shows only one line and the **Show dismissed** button.

Dismissed recommendations are copied when you clone the application and move with it in a server transfer.

## Permissions

Team members can see the recommendations. Only team admins and owners can apply, dismiss, or restore a recommendation.
