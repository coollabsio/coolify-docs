# Portabase

<ZoomImage src="/docs/images/services/portabase.svg" alt="Portabase logo" />

## What is Portabase?

Portabase is an open-source, self-hosted tool from a non-profit organization that helps you automate backups and restore your databases on demand. 

<Callout type="info" title="Agent setup required">

Before Portabase can back up your databases, you must configure an agent. See the [Agent setup documentation](https://portabase.io/docs/agent/setup?utm_source=coolify.io) for instructions.

</Callout>

## Features

- Easy to use and set up with interactive web interface.
- Supports multiple databases and storage backends.
- Provides automated backup scheduling and retention policies.
- Offers secure backup storage with encryption and access control.
- Supports backup restoration on demand with a simple click.
- Provides detailed logs and notifications for backup and restore operations.
- Notifications and alerts for backup failures or issues.
- Provides a REST API for integration with other tools and services.
- Provides a command-line interface (CLI) for advanced users and automation.
- SSO (Single Sign-On) support for user authentication and access control.
- OIDC (OpenID Connect), OAuth2 support for secure authentication and authorization.
- 2FA (Two-Factor Authentication) support for enhanced security.
- RBAC (Role-Based Access Control) support for fine-grained access control and permissions.
- MCP server to automate your operations, connect external tools, and interact with Portabase from AI agents.

and many more features.
