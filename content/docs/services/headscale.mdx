# Headscale

<ZoomImage src="/docs/images/services/headscale-logo.svg" alt="Headscale logo" />

## What is Headscale?

Headscale is an open-source, self-hosted implementation of the [Tailscale](https://tailscale.com) control server. It lets you run your own private WireGuard-based mesh network without relying on Tailscale's cloud infrastructure.
