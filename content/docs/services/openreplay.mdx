# OpenReplay

![OpenReplay](/docs/images/services/openreplay-logo.svg)

## What is OpenReplay?

OpenReplay is an open-source session replay and analytics platform that records what users do inside your application — clicks, scrolls, network requests, console errors, and state changes — so you can reproduce bugs and understand user behaviour without relying on third-party data processors.

It is a self-hostable alternative to FullStory and LogRocket. Because all session data is stored on your own infrastructure, it is a strong fit for teams with strict data-residency or privacy requirements.

## Features

- **Session Replay:** Watch pixel-perfect recordings of real user sessions, including mouse movements, input events, and page transitions.
- **DevTools Panel:** Inspect network requests, Redux/Zustand store state, console logs, and performance timings alongside the replay.
- **Co-Browse / Assist:** Live screen-sharing and remote control for support teams to assist users in real time.
- **Performance Monitoring:** Measure Core Web Vitals, JS errors, and slow resources across your user base.
- **Spot:** Async video bug reports — users record and annotate an issue directly in the browser.
- **Privacy Controls:** Granular input masking and element exclusion so sensitive data never reaches the recorder.
