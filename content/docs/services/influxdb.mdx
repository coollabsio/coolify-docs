# InfluxDB

## What is InfluxDB?

InfluxDB is an open-source time series database built for storing and analyzing timestamped data. It is commonly used for monitoring, observability, IoT applications, and real-time analytics.

## Features

- Optimized for time series data
- High-performance data ingestion
- InfluxQL and Flux query support
- REST API
- Integrates with Grafana, Telegraf, and Prometheus
