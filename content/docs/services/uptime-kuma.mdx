# What is Uptime Kuma?

Uptime Kuma is an easy-to-use, privacy-focused uptime monitoring service.

## Variants

- **Uptime Kuma:** Uses the embedded SQLite database.
- **Uptime Kuma with MariaDB:** Includes a MariaDB database.
- **Uptime Kuma with MySQL:** Includes a MySQL database.
