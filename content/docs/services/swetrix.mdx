## What is Swetrix?

Swetrix is a privacy-friendly, cookieless and open-source web analytics alternative to Google Analytics. Designed to be intuitive and not intrusive to your users privacy, Swetrix offers web analytics with real-time data, website speed monitoring, errors tracking, session analytics, and more.

## Upgrade to Swetrix v5

New services use Swetrix v5.5.4 with ClickHouse 26.8. An existing service keeps its image until you change it in **Configuration > General > Edit Compose File**.

1. Run the ClickHouse migration scripts from the release notes of v5.0.0, 5.1.0, 5.2.0, 5.3.0, 5.4.0, and 5.5.0.
2. Update the tracking script on your websites. It uses a new URL.
3. Update your API clients. The API is now at `<url>/backend`, through a new nginx proxy.

See the [official release notes](https://github.com/Swetrix/swetrix/releases?utm_source=coolify.io).
