# ALTCHA Sentinel

![ALTCHA Sentinel](/docs/images/services/altcha-logo.svg)

## What is ALTCHA Sentinel?

[ALTCHA Sentinel](https://altcha.org/docs/sentinel/?utm_source=coolify.io) is a self-hosted server that protects websites, forms, and APIs from spam, bots, and abuse. It uses the open-source [ALTCHA](https://github.com/altcha-org/altcha?utm_source=coolify.io) proof-of-work widget, so users do not have to solve image puzzles.

Sentinel adds spam classification, threat intelligence, IP and user-agent lists, and an admin dashboard. ALTCHA states that it does not use cookies or fingerprinting.

## License

ALTCHA Sentinel is proprietary software. It starts with a 30-day trial and does not need a license key for the trial. For production use, you must get a license from ALTCHA and enter the key in the admin dashboard under **Admin > License**.

See the [ALTCHA Sentinel license documentation](https://altcha.org/docs/sentinel/security/license/?utm_source=coolify.io).

## Deploy on Coolify

The template starts one container from `ghcr.io/altcha-org/sentinel`. Sentinel listens on port `8080` and keeps its database, Redis data, and generated secrets in the `altcha-data` volume.

Coolify generates these values for you:

| Variable | Description |
|---|---|
| `SERVICE_URL_ALTCHA_8080` | Public URL of Sentinel |
| `SERVICE_PASSWORD_ALTCHA` | Password of the `root` admin user |

To change the image version, set `ALTCHA_VERSION`. The template uses a pinned Sentinel v1 version by default.

<Callout type="warn">
Sentinel v2 uses a different port, configuration format, and data path. Do not set `ALTCHA_VERSION` to a v2 tag on an existing service.
</Callout>

## First login

<Callout type="warn">
The Sentinel dashboard login works only over HTTPS. On an `http://` URL, such as the default generated `sslip.io` URL, the login page shows **Security Requirement Not Met**. Set an `https://` domain for the service before you deploy it.
</Callout>

1. Deploy the service and wait until it is healthy.
2. Open the service URL.
3. Log in with the username `root` and the value of `SERVICE_PASSWORD_ALTCHA`.

Sentinel uses `SERVICE_PASSWORD_ALTCHA` only when it creates the `root` user on the first start. If you change the password in the dashboard, the variable does not change.
