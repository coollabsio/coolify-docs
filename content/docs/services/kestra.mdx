## What is Kestra?

Kestra is an open-source, event-driven orchestration platform. You define workflows in declarative YAML, from the built-in code editor or the no-code UI, and run them on a schedule, from webhooks, or in real time from message queues and file events. Kestra runs code in any language (Python, SQL, Shell, Node.js and more) and connects to databases, clouds and AI providers through its plugin catalog.

## Deployment notes

- `KESTRA_ADMIN_EMAIL` defaults to `admin@example.com`. Change it to your own email address before deploying, then log in with this email and the generated `SERVICE_PASSWORD_KESTRA`.
- The template runs Kestra in standalone mode with PostgreSQL, and mounts the Docker socket so script tasks can run in containers.
