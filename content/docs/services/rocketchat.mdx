## Upgrade to Rocket.Chat 9

New services use Rocket.Chat 9.0.0 with MongoDB 8.0. An existing service keeps its image until you change it in **Configuration > General > Edit Compose File**.

1. On MongoDB 7, set `featureCompatibilityVersion` to `7.0`.
2. Change the MongoDB image to 8.0.
3. Change the Rocket.Chat image to 9.0.0.

LDAP, SAML, and custom OAuth need a Premium licence. Some OAuth providers are removed.

See the [official release notes](https://github.com/RocketChat/Rocket.Chat/releases/tag/9.0.0?utm_source=coolify.io).
