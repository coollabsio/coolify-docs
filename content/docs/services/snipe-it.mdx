# Snipe-IT

<ZoomImage src="/docs/images/services/snipe-it-logo.webp" alt="Snipe-IT" />

## What is Snipe-IT

Snipe-IT is a a free open source system for asset management in IT Operations. Knowing who has which laptop, when it was purchased in order to depreciate it correctly, handling software licenses, etc.

### Initial Setup

After deploying the service, Snipe-IT will run some tasks to complete the installation in the background. Afterwards, you'll be met with the [Pre-Flight](https://snipe-it.readme.io/docs/pre-flight-setup) screen, which will help you determine whether your environment is set up correctly or not.
