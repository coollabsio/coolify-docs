# OpenWA

<ZoomImage src="/docs/images/services/openwa.png" alt="OpenWA logo" />

Open-source, self-hosted WhatsApp API gateway with a bundled dashboard.

## Variants

- **OpenWA:** Uses SQLite for storage in a single container.
- **OpenWA with PostgreSQL and Redis:** Includes PostgreSQL and Redis containers.
