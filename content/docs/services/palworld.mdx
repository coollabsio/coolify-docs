## What is Palworld?

Palworld is a multiplayer, open-world survival and crafting game where you can befriend and collect mysterious creatures called "Pals" in a vast world. This service allows you to host a dedicated Palworld server for you and your friends.

## Features

- Dedicated server hosting
- Multiplayer support
- Persistent world
- Custom server configuration
- Save game management

## Upgrade to Palworld server v2

New services use palworld-server-docker v2.8.1. An existing service keeps its image until you change it in **Configuration > General > Edit Compose File**.

1. Back up the server data.
2. Use the REST API on port 8212. RCON is deprecated.
3. Use `PLAYERS`, not `MAX_PLAYERS`.

See the [official release notes](https://github.com/thijsvanloef/palworld-server-docker/releases/tag/2.0.0?utm_source=coolify.io).
