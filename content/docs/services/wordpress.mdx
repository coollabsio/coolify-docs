## What is WordPress?

WordPress is a free and open-source content management system written in PHP and paired with a MySQL/MariaDB database.
It is used for creating websites, blogs, and applications.

## Deployment Variants

- **WordPress with MariaDB:** Includes a MariaDB database.
- **WordPress with MySQL:** Includes a MySQL database.
- **WordPress without Database:** Uses an external database that you configure separately.

<Accordion title="How to increase the upload size limit?">

You can increase the upload size limit by following these steps:

1. Open the `.htaccess` file through Coolify's Terminal (or through SSH, and docker exec -ti `container_id` /bin/sh)
2. Add the following lines to the end of the file with `vi` or `nano`:

```php
# END WordPress - this line already exists in the file

php_value upload_max_filesize 256M
php_value post_max_size 256M
php_value max_execution_time 300
php_value max_input_time 300
```

3. Save and close the file.
4. Reload the website in your browser. The changes should be applied automatically.

</Accordion>

<Accordion title="How to fix a redirection loop in WordPress?">

If your WordPress site is stuck in a redirection loop, follow these steps to resolve the issue:

Access the .htaccess file:

1. Open the `.htaccess` file through Coolify's Terminal (or through SSH, and docker exec -ti `container_id` /bin/sh)
2. Navigate to the WordPress root directory and locate the .htaccess file. Edit the .htaccess file:

```
<IfModule mod_setenvif.c>
  SetEnvIf X-Forwarded-Proto "^https$" HTTPS
</IfModule>
```

3. Save and close the file.
4. Reload the website in your browser. The changes should be applied automatically.

</Accordion>

<Accordion title="Why does the login redirect to my old domain after a domain change?">

WordPress keeps its site address in the database. It saves the address that you use when you install WordPress. Coolify does not change this address when you change the domain of the service. If the two addresses are different, the login redirects you to the old domain.

To change the domain, do these steps:

1. In Coolify, add the new domain next to the old domain, separated by a comma (for example `https://old.example.com,https://new.example.com`). Then redeploy the service.
2. In WordPress, open **Settings → General**. Set **WordPress Address (URL)** and **Site Address (URL)** to the new domain, then click **Save Changes**.
3. In Coolify, remove the old domain and redeploy the service.

If you already changed the domain and the login redirects you to the old domain, change the address in the database:

1. In Coolify, open the **Terminal** of the database container (`mariadb` or `mysql`).
2. Run this command. Replace `https://new.example.com` with your domain. For the MySQL template, use `mysql` instead of `mariadb`.

```sh
mariadb -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE" -e "UPDATE wp_options SET option_value = 'https://new.example.com' WHERE option_name IN ('home', 'siteurl');"
```

3. Log in to WordPress on the new domain.

These steps do not change links that are saved in posts and pages, for example image URLs. To change those links, use a search-and-replace plugin such as Better Search Replace.

</Accordion>

<Accordion title="How to set up WordPress Multisite?">

1. **Add WordPress** with the one-click installation.

2. **Persist WordPress files on the host.** In the Compose configuration (edited from the UI), change:

   ```yaml
   volumes:
     - "wordpress-files:/var/www/html"
   ```

   to:

   ```yaml
   volumes:
     - "./wordpress:/var/www/html"
   ```

   This mounts the `wordpress` directory inside the service's configuration directory (`/data/coolify/services/<serviceUuid>/`) to `/var/www/html` in the container, so files you edit on the host are reflected in the container.

3. **Configure WordPress.** Start the service and complete the initial setup.

4. **Disable all plugins.** In the WordPress admin panel, go to **Plugins → Installed Plugins**, select all plugins, and choose **Deactivate**.

5. **Enable Multisite.** Edit `wp-config.php` on the server and add:

   ```php
   define( 'WP_ALLOW_MULTISITE', true );
   ```

   Refresh the WordPress panel; a new **Network Setup** item appears under the **Tools** menu.

</Accordion>
