# Keila

<ZoomImage src="/docs/images/services/keila-logo.svg" alt="Keila logo" />

## What is Keila?

Keila is an open-source newsletter and email campaign tool for managing contacts, campaigns, signup forms, and self-hosted email sending workflows.

## SMTP Configuration

Keila needs an SMTP provider before it can send campaigns. When creating the service, configure the required SMTP values such as the host, port, sender address, username, password, and TLS or SSL mode.
