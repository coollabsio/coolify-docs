# Inngest

<ZoomImage src="/docs/images/services/inngest-logo.svg" alt="Inngest logo" />

## What is Inngest?

Inngest is an open-source durable workflow engine for background jobs, queues, scheduled work, and event-driven functions. Applications send events over HTTP, and Inngest manages execution, retries, and individual workflow steps.
