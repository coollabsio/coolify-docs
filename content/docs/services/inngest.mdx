# Inngest

<ZoomImage src="/docs/images/services/inngest-logo.svg" alt="Inngest logo" />

## What is Inngest?

Inngest is an open-source durable workflow engine that allows you to build reliable background jobs, queues, and event-driven systems. It provides step functions, automatic retries, scheduling, and fan-out — all without managing infrastructure like queues or workers. Inngest works with any language or framework by receiving events over HTTP and executing your functions durably.
