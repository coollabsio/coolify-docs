# Bookstack

## What is Bookstack

BookStack is a simple, self-hosted, easy-to-use platform for organising and storing information.

## Initial login

After deploying the service, open your BookStack URL and log in with an admin user.

If you cannot log in, or if you want to create a new administrator, open the **Terminal** for the BookStack container in Coolify and run the BookStack admin creation command.

## Create an admin user

### Interactive mode

Run:

```bash
php /app/www/artisan bookstack:create-admin
```

You will be prompted for the admin name, email address, and password.

### Create an admin with a generated password

For a new installation, you can create an admin user and let BookStack generate a secure password:

```bash
php /app/www/artisan bookstack:create-admin \
  --email="admin@example.com" \
  --name="Admin" \
  --generate-password
```

BookStack will print the generated password in the terminal. Use that password for the first login, then change it from the user profile if needed.

### Set the initial admin user

For first-time setup or automation, use the `--initial` option:

```bash
php /app/www/artisan bookstack:create-admin \
  --initial \
  --email="admin@example.com" \
  --name="Admin" \
  --generate-password
```

The `--initial` option is useful when setting the first administrator for a fresh instance.
