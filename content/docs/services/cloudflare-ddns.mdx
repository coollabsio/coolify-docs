# Cloudflare DDNS

<ZoomImage src="/docs/images/services/cloudflare-ddns.svg" alt="Cloudflare DDNS logo" />

## What is Cloudflare DDNS?

Cloudflare DDNS detects changes to the server's public IPv4 or IPv6 address and updates selected DNS records through the Cloudflare API.
