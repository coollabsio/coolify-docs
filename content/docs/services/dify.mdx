# Dify

<ZoomImage src="/docs/images/services/dify.png" alt="Dify logo" />

Open-source platform for building LLM applications with workflows, retrieval-augmented generation, and AI agents.

## Setup

New services use Dify 1.19.0, based on the official Docker Compose file of Dify.

1. Deploy the service and open its domain.
2. Dify opens its setup page (`/install`) and asks for the init password. Copy the value of `SERVICE_USER_INITPASSWORD` from **Environment Variables**.
3. Create the admin account.
