## What is Gitea?

Git with a cup of tea! Painless self-hosted all-in-one software development service, including Git hosting, code review, team collaboration, package registry and CI/CD.

## Deployment Variants

- **Gitea:** Uses the embedded SQLite database.
- **Gitea with PostgreSQL:** Includes a PostgreSQL database.
- **Gitea with MySQL:** Includes a MySQL database.
- **Gitea with MariaDB:** Includes a MariaDB database.
- **Gitea Runner:** Standalone Actions runner for an existing Gitea instance.
