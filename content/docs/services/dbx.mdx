# DBX

![DBX](/docs/images/services/dbx-logo.png)

## What is DBX?

DBX is a lightweight, open-source database client with a web interface. It supports more than 90 databases, for example PostgreSQL, MySQL, SQLite, MongoDB, and Redis.

Use DBX to connect to your databases, run queries, and examine data from your browser.

## Deploy on Coolify

1. Go to **Projects > New Resource**.
2. Select **DBX** from the service list.
3. Click **Deploy**.
4. Open the generated URL, then log in with the password in `SERVICE_PASSWORD_DBX`.

## Environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `DBX_PASSWORD` | Yes | Web login password. Coolify sets it to the generated `SERVICE_PASSWORD_DBX` value. |
| `DBX_VERSION` | No | Image tag. The template pins a tested version. |

## Persistent storage

The `dbx-data` volume keeps the saved connections and settings in `/app/data`.
