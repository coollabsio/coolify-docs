# Healthchecks

<ZoomImage src="/docs/images/services/healthchecks.webp" alt="Healthchecks logo" />

## What is Healthchecks?

Healthchecks monitors cron jobs and scheduled tasks by waiting for HTTP requests or email messages. It sends an alert when an expected ping does not arrive on time.

## Create the first account

After deployment, create an account through an emailed magic link or run the Healthchecks `manage.py` command in the application container to create a superuser. Magic-link authentication requires working email configuration.

Read the [Healthchecks Docker documentation](https://healthchecks.io/docs/self_hosted_docker/) for the supported account-creation commands and email settings.
